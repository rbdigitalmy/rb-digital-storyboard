# RB Digital Storyboard

RB Digital Storyboard is a React portal, ChatGPT Extension and authenticated
Streamable HTTP MCP server for 19 short-form visual storytelling workflows.

## Production

- Portal: https://rbdigitalmy.github.io/rb-digital-storyboard/
- MCP: https://klxzpyzgljvmsepvjhaz.supabase.co/functions/v1/mcp-server
- Hosting: GitHub Pages
- Auth, database and Edge Functions: Supabase

## Development

```bash
npm install
npm run dev
npm test
npm run build
```

Deployment and OAuth configuration are documented in
[`DEPLOYMENT.md`](./DEPLOYMENT.md).
